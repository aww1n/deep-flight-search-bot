# Contributing

1. Создайте отдельную ветку от `main`.
2. Установите зависимости: `python3 -m pip install -e '.[dev]'`.
3. Внесите изменения и добавьте тесты.
4. Выполните `make check`.
5. Откройте pull request с кратким описанием поведения и рисков.

Новые источники цен должны работать через публично разрешённый интерфейс, не обходить CAPTCHA,
авторизацию, anti-bot-защиту или rate limits и не выдавать неподтверждённые цены за актуальные.
