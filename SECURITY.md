# Security Policy

## Reporting a vulnerability

Не публикуйте секреты или детали уязвимости в открытом issue. Отправьте приватное сообщение
владельцу репозитория через его GitHub-профиль. В сообщении укажите затронутую версию,
способ воспроизведения и возможное влияние.

## Secrets

- Никогда не коммитьте `.env`, Telegram token или OpenAI API key.
- Если ключ случайно опубликован, немедленно отзовите его у провайдера и создайте новый.
- Для облачного деплоя используйте secret/environment variables платформы.
